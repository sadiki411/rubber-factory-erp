# A5 现场手机/弱网验收记录表

本表用于真实安卓设备记录，不以电脑浏览器、模拟器或“感觉很快”替代。每条关键路径至少100样本，并单独做20/50张队列场景；扫描识别、识别后查询、本地队列反馈、最终保存分别计时。样本不足100可作现场试用记录，不宣布P95达标。

配套[现场分段采样器](prototypes/a5-field-sampler.html)不连接ERP，仅记录计时并可导出JSON；建议第二台设备计时，单机切换带来的误差要备注。未计时段保留未测，不填0。隔离自动化工具是`scripts/verify_a_ui.cjs`（只允许localhost预览）、`scripts/benchmark_analytics_scale.py`（内存测试库）和后端`test_a_resilience_concurrency.py`。

## 必做场景

1. 20 张、50 张连续扫码，含 1 张查询失败卡和 1 张重复卡；失败卡必须保留并可单独重试，不能误判为首次绑定。
2. 在隔离环境让保存成功但响应断线，以及未提交到服务器两种情况：扫码退货先点“重新核对提交结果”。已有记录必须拦截并核实，不猜归属；未见记录才可再次提交。重量出货保持同一client key。
3. 两台手机同时登记同一物理批次，仅限测试环境：预期一成功、一已占用或明确未入账503；服务器稳定后重试应被已有记录拦截，最终只一条有效业务记录。不要在正式库造测试退货。
4. 确认、更正、退货、再次出货后，在 5 秒内刷新相关页面核对数量、状态和员工统计。
5. 现场相机不可用时标记“相机未测”，不能用手工输入结果冒充相机通过。

## 判定

- 已识别码后的本地队列反馈 P95 ≤ 300ms；不是相机识别或服务端API目标，真实端到端另报。
- 单卡精确查询 ≤ 1s，首次路径 ≤ 2s，小批确认 ≤ 2s：若不达标记录网络、设备和接口时间。
- 发生“未知结果”时先查询操作 key/单号再决定是否重试，禁止盲目再次提交。

现场先确认环境和账号，使用实际需要处理的业务记录，正式库不要为了测试制造退货/恢复旧备份。相机100样本可重复读码但不重复保存；并发、超时、确认/更正/再出货验证使用隔离测试库。70×50模板本轮未改，实物热敏打印单列待现场测试。手机打不开本地采样器时，可用电脑/第二设备记录，不能据此冒充安卓相机通过。
