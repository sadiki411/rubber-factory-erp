# 产品规格资料：标准维护与导入

## 入口及来源

- 原“产品规格资料”列表右上新增“导入工艺 / 检验标准”：先选已有产品，再选择xlsx。
- 产品查看、编辑页顶部“硬度、尺寸与产品标准”，可手填或导入，查看页直接显示标准。
- 原“导入产品规格”继续处理产品基本资料，不替换原入口、不另建平行产品主档。
- 订单选择原有产品规格资料，引用同一产品关联标准。未明确适用客户、料号、模具或订单特规时，不以相同规格猜配。
- 硬度与公差来自客户标准书、图纸或人工确认的本厂实际依据；不从材质代码、产品规格或参考图片推算。

## 可维护字段

1. 成型硬度、烤后硬度及尺寸：上下限、仅上限/仅下限、严格/包含边界、单位/量表、测法、确认状态、是否随包测。
2. 硬度对象：成品/当批胶料自制胶片、仪器、测点、调节、读数时间、客户认可测法。
3. 工艺：上下模设定温度与接触温度目标分开，硫化时间保留原单位，压力类别及单位、排气、排料、脱模剂、毛边洒油、机型、生产注意事项。
4. 二烤：待确认/需要/确认不需要，温度及时间上下限。只给单位不等于0或不需要。
5. 来源与适用范围：依据、客户、客户料号/图号/版次，特规仅对应明确订单项次。
6. 随包路线和包装：整模、实测、巡检、毛边、二烤、品检、每包模数、巡检间隔、四项外观。

“保存草稿”不生效；“保存并生效”增加标准版本。尚未核实的字段仍为待核，生效版本不代表现场已执行，关键要求未确认仍不能正式发卡。

## 保存和历史边界

- 仍关联原`orders.ProductSpecification`及`ProductInspectionCriterion`，`flowcards.StandardRevision`仅为同产品的版本及冻结快照，不是第二套产品主档。
- 修改旧要求生成明确新版本/覆写行，不静默改写旧要求行、历史标准或已发卡快照。
- 新导入保存文件名、工作表、行号、原文、SHA-256及识别身份；不声称保存了原xlsx文件二进制附件。
- 常规图纸要求可以保留但不随包测，不计入随包测项数；旧快照缺少该开关时保持原行为。
- 订单专用要求仅关联唯一明确订单项次，不能保存成长期通用标准。
- 本轮不改订单数量、生产、库存、交付、退货账，不自动发布正式打印模板。

## 导入范围和限制

按字段标签识别项目/要求列、横排条件块及订单补充；支持全角斜杠表头、上下限、±公差、非对称公差和严格大小于。文件8MB以内、解压50MB以内、最多30工作表、3000行80列；保存来源原文过大时提示按单产品拆分。

这不是任意版式OCR：图片、公式或未识别字段保留原文供核对，不能保证自动理解所有客户表格。身份冲突前后端拒绝带入/保存，缺硬度量表或测法不猜填。

## 验证边界

用户两份xlsx字节相同，均为隔离合成验收样表，三标准块分别对应不同产品或订单特规；大厂图片仅作字段参考。所有试填在全新合成库，正式站仅备份、迁移、只读核对。

自动测试覆盖解析、上下限边界、严格小于、下限、无dimension元数据、全角表头、来源保留、产品身份拒配、特规隔离、版本历史、只读权限和失败提示。浏览器验收包括真实样表上传、产品错配提示、标准保存读回及390px手机窄屏。发布流水线及正式站结果另记录在本次上线验收报告，不把未验证写为通过；安卓实体设备和打印机未测。
