# 生产参数查看补齐与字段核对

日期：2026-11-09。检查基线：`c65694975855b6f7aa6cb34bcde9a70819789df6`。

## 范围与根因

用户要求手机和电脑无需进入编辑，即可查看大条条重及数量、小条条重及数量、一模排料总重，并检查原有生产必需参数是否遗漏。

原有产品及生产接口已经返回四个条字段，编辑表单也已具备；只读产品摘要、生产记录详情、生产手工账卡片遗漏了展示。不是数据没有保存。本轮只调整前端读路径，不变更保存接口、数据库结构、正式数据、库存或生产进度算法。

## 显示规则

- 重量单位g，至多两位小数；数量单位条。只有大条、没有小条是允许的，空值显示“未填写”。
- 一模排料总重 = 大条条重 × 大条数量 + 小条条重 × 小条数量（小条两项均未填时不加）。例如21g×5＋11g×2＝127g。
- 仅完整的参数组参与总重展示；小条只填一项时，显示“参数不完整，暂不计算”，不拿部分结果充当总重。
- 已明确保存的0g显示0，不回退到历史非零值。界面按百分之一克计算展示，避免小数浮点尾差；不更改后端历史计算或任何正式账。
- 仅旧`strip_weight_kg / strips_per_batch`存在时，单独标“历史单条条重 / 历史每批条数”，重量换算为g；不擅自认定为新的大条 / 小条字段。
- 任务只显示任务已保存参数；产品后续修改不会自动替换历史任务。需要参考产品资料时仍进入产品只读查看，不将参考条件当作任务快照。
- 排料总重是成型前投入，不是成品重量，不参与库存、良率或出货件数计算。
- 产品桌面新增只读参数列；手机采用两列可换行参数格；总重独占一行。手工账五项直接显示，其他参数只读展开，避免把常用交接按钮淹没。
