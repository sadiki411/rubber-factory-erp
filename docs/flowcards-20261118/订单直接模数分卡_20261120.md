# 订单直接填写预计模数并打印

## 依据与范围

用户2026-11-20明确：在订单管理直接打印，填写预计360模，自动分为100、100、100、60；逐卡及尾数可修改。不必先到生产页建任务。

此前“必须先有真实生产段才能制卡”的交互限制在此范围废止。保留生效标准、订单/客户/产品身份核对及旧卡快照保护，不虚构机台、孔数或实际报产。

## 当前操作

1. 订单管理电脑操作列、手机订单卡片点击“制卡 / 打印”。
2. 填写“本次预计生产模数”，默认每张100模；360模分为100、100、100、60。
3. 逐张可改、增卡、移除；显示合计和差额。比如改成100、100、90、70仍合计360。
4. 如计划总量本身改变，可点“预计模数改为分卡合计”。更改预计总数或默认每张模数会重新自动分配；按钮“按默认模数重新分配”也可恢复默认。
5. “生成并准备打印”保存同一草稿、生成原卡号并准备原PDF；点击“打开原PDF”后按原尺寸100%打印。超过100张按页分批打印。
6. 生成后不能改写原卡；补打沿用原号、原标准和原模数。另有生产计划时明确另建，不默认为重复打印。

## 数据边界

- 使用现有CardGroup与InternalCard，分配保存到snapshot.card_molds，生成后每卡planned_molds为实际分配值；不新增表或迁移。
- 订单入口显式order_plan=1，不自动猜配某个已有生产段；记录ORDER_EXPLICIT计划来源。
- 无生产段时不猜有效孔数，不产生ProductionRun、ProductionDailyLog、品检、库存或交付数量。
- 生产入口仍保留原范围与重叠限制，且能够找到同订单尚未绑定生产段的原卡，防止另发一整套；本轮未自动绑定旧卡到后续生产任务。
- 每卡1至100000的整数，最多500张，合计必须等于预计总模数；前后端均校验。
- 已有订单卡再次新建须明确确认另一批计划。生成请求幂等，草稿保存版本冲突仍受保护。
- 同一组未确认打印结果的任务可精确恢复；不复用部分确认或混入其他卡的任务。下载不等于实印成功。
