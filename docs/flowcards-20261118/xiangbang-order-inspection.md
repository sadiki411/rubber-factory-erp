# 翔邦订单的客户检验要求

- 同一次订单导入按表头识别两张表，按独立需求号、项次关联；下单方翔邦、协力商、终端客户代号分开。订单原表的计划用料、参考工时不计实际。
- 「订单管理 → 完整查看」可展开每个类别、查看原文件或下载检验标准 PDF。产品规格资料可同时看不同客户/项目的标准版本。工序卡原版式保留，只在原客户栏印代号；发卡时的完整要求在卡详情下载，不发生补打计数。
- 类别 `2001` / `6001` 含义未确认，均原样保留，不自动映射现场岗位或判客户放行。核对原表与本厂工序标准是两件事；生成正式工序卡仍沿用已确认本厂工艺规则。已发卡只展示当时保存的内容。
- 同一产品、同一客户及项目、同类别和版号且所有限值相同，复用已核对内容。改变范围、版号或数值需重新核对。同客户且技术要求一致才可共卡，不改变生产或出货原规则。缺检验表，有明确的客户和项目才自动沿用唯一现行版；否则可由有权限的人确认客户项目再选择。
- 翔邦一次加硫把原表误写 `min` 的数值按秒读取，数值不乘 60，保留原文。二烤使用分钟；当温度与时间均明确为 0 时为无需二烤，不代表实测。
- 仅补历史原表：使用 `supplement_xiangbang_inspection`，以原文件 SHA-256 和预期订单/检验行数限制范围。默认只读预核对，随后显式 `--apply`；原行身份、来源或内容不符时整批停止。补充不改订单数量、交期、状态、历史卡、PDF，也不代为核对。
