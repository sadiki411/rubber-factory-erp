# 工序流转卡：A4 双卡、原尺寸单卡与 A5 横向

- 从订单制卡、原卡组或单卡详情的「打印任务」进入。默认「A4 双卡打印」，也可改成「原尺寸单卡」。A4 纵向、实际大小 100%、每张纸 1 页（PDF 内已经排好双卡）。
- 每页上、下各排一张选中的原卡，按组内批序排列，中间有细虚线用于裁切。末页为单数时下半留白；单独补打只选当前卡，不补入其他卡。原标准或记录太长而有续页时，续页按原卡号另排在主卡之后，不填入奇数尾页。
- 样张和纸张预览不发号、不生成打印任务、不计补打、不可扫码。正式 PDF 保留原卡号、二维码、当时表单版次和既有补打确认逻辑。
- 纸张格式与是否二检随打印任务冻结，恢复或下载时沿用原任务，不覆盖旧文件。没有纸张格式字段的历史打印任务按原尺寸处理。仅「确认成功」才记实际打印。
- 自动回归覆盖 8 / 5 / 1 张的 PDF 页数和卡位、原尺寸、只读预览、原任务恢复和补打确认；打印机实际出纸和纸面扫码需在现场检查。

## 2026-11-28：A5 与同规格材质跨订单打印

- 在「纸张排版」可选 **A5 一卡打印（A4 对折）**。ISO A5 是 148×210 mm；工序卡印横向，PDF 为 210×148 mm。使用 A5 纸、横向、实际大小 100%、每张纸 1 页，不用浏览器再设置拼版。已有长卡原续页随卡保留。原 A4 双卡和原尺寸模式不变。
- **订单管理 → 批量打印工序卡**，输入规格、材质，勾选明确项次，点「汇总所选订单的卡」。已有正式原卡才可入选；若同一卡关联两个选中订单，只入列一次。未制卡从订单原入口完成。过滤顺序、日期不会用来推断实物关系。
- A5 批量任务复用各卡发号时的渲染版本和逻辑纸型，在标准 A5 纸面统一排放，即使旧卡尺寸或版式不同也不套新模板。不同产品档案、客户或客户身份待核的组分册；非 A5 模式不同版式或原尺寸也分册。每册最多 100 张，大任务可逐册打印；打印时每册可再取消勾选个别卡。
- 默认只汇总未确认出纸且没有其他待处理任务的卡。已生成但未出纸的旧任务可继续或按实际情况取消，不另算补打；已确认出纸的卡须勾选「包含已打印卡（补打）」。预览不建立打印任务、不计补打，不改变订单、生产、库存、出退货或卡标准。
- 验证：隔离库工序卡后端 145 项通过（含 `flowcards.test_a5_batch_print` 的精确规格材质、共享卡去重、两单混合旧版冻结纸卡、三张 A5 三页、占用和补打保护、超过百张分册），前端三组测试共 18 项、TypeScript 类型检查及构建通过。合成双订单样张经 Poppler 核实 210×148 mm，两页逐页查看未见裁切。普通员工用 390px 浏览器从订单管理选两单，预览时打印任务数仍为 0；正式样式 PDF 两页，纸面两枚二维码经软件解码分别对应各自原卡，打印任务仍待确认。未接触正式账、实体打印机或安卓实体设备；本变更未部署。

## 2026-11-28：可增删外观检查项目

- 「详细工艺与检验标准 → 打印项目」选择、移除，或输入一个新名称点「新增并选入」。同名有效项目复用，保存标准才改变以后新制卡的默认项目。只这批临时不同，可在制卡页「本次纸卡 · 外观检查」选项目，不改产品标准。正常、其他仍保留；无须凑四项，最多二十个具名项。
- 外观栏属于巡检；未开启巡检不印该栏。发号时冻结本批明确选中的外观项目。已发原卡、历史标准、打印次数或历史 PDF 不改；打印任务也不会把修改后的新标准套到旧卡。
