## 2. A—D 逐项增量

| 项目 | 根因与本轮修改 | 验证边界 |
| --- | --- | --- |
| A：常规线径、单边上限 | 原数值校验强求上下限，关闭数值判断又无法提示超限。现在区分仅上限、上下限、界限待确认、不要求测；边界明确包含或严格不包含。产品检验项目→确认版本→卡组快照→PDF→手机→详情使用同一限值语义。仅上限下限留空；已有下限不得偷偷忽略。复用项目仍保订单、工作表和原行号来源 | 新增后端边界/快照/来源断言；前端文案断言；两份 PDF 及真实本地页面操作。没有规定每模必测、多点取最大或抽样频次，没有从名义规格推公差 |
| B：输入实测和首屏复核 | 原表单可保留“未知＋数字”，正确超限也埋在记录里。现在输入数字切实测、清空切未测；改回非实测时明确提示清掉本次未保存读数，服务端拒绝矛盾状态并重算判定。有效超限直接在首屏显示项目、原读数、限值、差值、卡号、人员时间和复测入口，无须再填一份异常 | 普通隔离用户实际填 3.06、看超限、关联复测 3.04；原 3.06 保留。自动测试包括原请求重试、伪造客户端判定、未判定复测不解除提醒、链尾继续复核和禁止分叉。仅本次测量结论，不判整批、不退货、不扣库、不改绩效 |
| C：从实际二烤登记胶片硬度 | 原入口要抄内部作业 ID。现在二烤原记录提供“记烤后硬度”，按业务时间、盘号、胶片、胶料选择；自动带入作业及完整代表卡范围，不默认最近一次。每次二烤单独展示胶片检测结果，无对应胶片保持未测 | 页面实际完成一次二烤→快捷带入→硬度 70 保存。两卡共用一次测量及其中一卡再次烤未随胶片，由后端隔离测试验证；未把单卡 UI 演示冒充双卡全程实操。最后增加的各次二烤摘要由自动测试验证，未单独重拍该摘要 |
| D：纸面身份与长字段 | 原卡号换行丢连字符。新纸卡第一行保留末尾“-”，手查兼容这个明确换行，不补丢字、不按尾号猜卡。长字段首页优先保短编号、材质和简明规格，原文留同号续页；有缺要求时不再笼统写“已确认” | 自动验证电子码文本和完整/分行手输指向同卡、错一位不误认、旧 v2 渲染字节不变、长身份可容纳。两张新样卡逐页渲染目检；未进行本轮新 PDF 的电子图像二维码解码或安卓实扫 |
