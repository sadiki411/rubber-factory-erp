## 桌面与窄屏（只读即可）

视口分别设为 1366×768、1440×900、768宽、390宽、320宽，每种记录实际高度、浏览器版本和截图。

1. 首页：标题不竖排；首屏在1366×768至少完整显示5条紧凑待办；查模具/扫库位入口可到达。切今日交期、逾期、未来7日、全部，所有历史仍可查。
2. 品检：主动作在首屏，现场操作与历史查询清楚分区；更多筛选可打开，已启用条件可清除；扫码、重量、无卡件数及无扫码整批退回入口均保留。整页不能横滚，明细表可以表内横滚。
3. 用只读账号打开品检原单和产品资料：可查看，写入按钮禁用；不要实际尝试保存正式数据。
4. `/analytics?date_from=2026-10-01&date_to=2026-10-31&tab=quality`：月份和区间一致，10月可读取；跨月区间显示“自定义”；刷新和浏览器返回后区间一致。断网重读只显示失败，不显示假0或旧数据冒充成功。
5. 待办 R111：直接打开该退回单，关闭后可见查询结果；返回保留待办分类、搜索、页码。按卡 `04-M003-2607090266` 查历史，应完整看到9条明确关联退回，未登记作业不能说成作业0次。
6. 订单90：需求、净交付、欠交在首屏，默认概览；各节所有来源分页可访问。订单200没有关联生产时应说“未关联生产记录”。来源记录持续变化，以本轮验收报告快照为对照，不强制凑旧数字。
7. 库存：`K02-L04-P03`完整可读；`K02-L03-P05`不合格不呈绿色。待办进入内部库位详情，返回仍在原筛选；微信公开二维码仍只读，不获得编辑权限。
8. 产品点击先看摘要，再单独编辑；二烤标为参考，不显示“本批已执行”。模具机台图、库存货架图保持可用。

可在开发者工具粘贴 [只读布局测量工具](../scripts/browser_layout_audit.js)，保存返回的尺寸与截图。该脚本不发请求、不修改记录。测量不能替代肉眼检查遮挡、键盘与触屏。

## Android / 相机 / 弱网（未实机验收）

1. 记录安卓型号、系统、App版本、网络。正常打开首页、订单、品检、库存，返回按钮不丢失原筛选；确认本轮网页更新加载到App。
2. 扫码先用只读查模具/库位，验证相机授权、扫码、关闭、返回和键盘弹出不挤掉主要按钮。正式出退货只能在真实业务发生时按原流程操作，不为验收增加账。
3. **写入弱网/并发必须隔离环境**：开启请求延迟/丢响应，双击确认、重复扫码、提交后刷新、两用户操作同一批；记录请求编号、返回、最终有效事实条数及库存余额。现有后端并发回归是技术证据，不能冒充现场网络验收。
4. 确认失败时不显示成功；成功但响应丢失时先查询原单，不盲目反复新增。不得手动补造丢失与否不确定的历史。
