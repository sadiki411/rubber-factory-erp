# 订单导入：模具型号关联与在厂核对

## 需求与边界

用户在2026-11-16确认：首次导入可人工关联模具型号，后续沿用该产品已保存的型号，展示该型号下各副实物的位置和状态。不固定某一副实物；上机是“在厂、占用”，不是缺模。未关联、客户收回、未找到启用的实物档案等仅提醒，不新增阻止导入的确认门槛。台账缺失不代表已经证明实物不在厂。

保留原有料长核对及确认规则、产品身份歧义校验、订单重复与历史版本保护。本轮不更改生产分配、出退货、库存或订单数量，不创建模具、不移动模具、不猜配旧产品，也不重算旧导入历史。

## 入口与操作

订单管理→导入→预检，新增“订单模具在厂核对”。翔邦工作联络单、内部订单、采购单图片预检均接入。

1. 查看每个产品涉及的订单号、项次、客户原表模具号。
2. 第一次可按模具型号或名称搜索，选中已有型号；型号选项同时显示在库、上机、客户收回数量。
3. 展示所选型号全部启用实物的编号、库位或机台、状态。可点击“重新核对模具状态”。
4. 人工选择先保存在本批次草稿，只有整批导入事务成功才保存到产品档案；关闭或取消预检不会悄悄改正式关联。清除只撤销本次选择，不删除已保存产品关联。正式修改或解除关联仍在产品规格资料进行。
5. 后续导入优先沿用产品档案已保存型号；客户原表自动匹配不得覆盖已保存关联。本次人工选择优先于原表自动匹配。
6. 导入历史显示提交时重新读取的状态快照及关联保存警告，不因之后移动模具而改写过去。

没有查到型号或实物时，仍可沿用原导入操作继续；原文件格式错误、产品身份不唯一等既有校验不因本功能而取消。

## 状态定义

|状态|判断|处理|
|---|---|---|
|在库|启用型号至少一副启用实物为在库|展示全部实物；通常不提醒|
|在厂·上机占用|没有在库实物，但至少一副启用实物上机|不算缺模，显示机台|
|客户收回|型号启用实物均为客户收回|提醒确认返厂；允许导入|
|未找到实物档案|已有型号，但没有启用实物记录|提醒补核台账；不直接断言实物不在厂|
|待关联|产品尚无型号关联，客户模具号也未精确匹配|可人工选择或继续|
|型号停用/不存在|已保存或草稿型号不再有效|提醒核对，不自动替换，不因缺模阻止导入|
|产品身份待确认|产品有歧义或已停用，不能安全保存关联|不猜配；原产品校验照常执行|

多副实物混合状态时，标题优先在库、其次上机，逐副明细不隐藏客户收回的其他实物。客户模具号与已保存型号冲突时另给提醒。

## 产品匹配与安全保护

- 既有来源键、明确产品身份匹配仍优先；不能仅凭规格相似选择产品。
- 人工关联后产品规范键可能包含ERP型号，而新文件仍含客户原始模具号。翔邦来源增加唯一身份回退：规格、材质、客户产品号必须一致；没有客户产品号时还要求原表模具号一致。多个候选不猜配，即使有关联的候选排在第四条之后也不能漏判。
- 客户原表模具号及产品的ERP型号关联分开保留。
- 提交前复检；型号失效或产品关联在预检后被别人修改时，不覆盖最新关联，保留订单导入并返回明确警告。
- 选择草稿与提交都限制为批次所属用户；既有只读账号不能调用写接口。产品关联变更写既有业务修订审计。
- 导入与关联在同一事务。审计或其他保存失败时一起回滚，按原流程标记失败批次，不留下部分导入；失败后重新预检。
- 图片内容重新预检会撤销该批次旧的人工模具选择，防止改了产品却沿用先前选择。

## 技术实现与测试定位

- 服务：`backend/orders/mold_checks.py`：`build_mold_check`、`update_mold_selection`、`apply_mold_selections`。
- 草稿接口：`POST /api/orders/imports/<token>/mold-check/`；空对象刷新，包含`binding_key`和`mold_model_id`则选择，`null`撤销本次选择。
- 导入提交在既有`commit_business_batch`事务尾部保存人工关联及实时快照；导入历史直接读快照。
- 前端组件：`ImportMoldCheck`；宽度可收缩、长选项换行，关闭下拉虚拟固定行高以避免手机截断，主要控件至少44px。
- 后端专项：`orders.tests.test_mold_checks`和采购图片新增回归；覆盖缺模不阻导入、多实物状态、重复导入数量不重记、已保存关联保护、人工优先、并发保护、失效型号、回滚、只读权限、历史快照及歧义产品。
- 前端：`ImportMoldCheck.test.tsx`、导入抽屉、历史抽屉、采购图片测试；覆盖失败保留原结果、选择未保存前禁提交、缺模仍可导入及历史不可编辑。
- 501条同产品订单核对固定3条SQL，不随订单条数逐条查模具。尚未保证任意规模数据均达到某个端到端时间指标。

无模型变更、无新增迁移；安卓原生功能未改，App使用同一线上页面，一般无需重新安装APK。
