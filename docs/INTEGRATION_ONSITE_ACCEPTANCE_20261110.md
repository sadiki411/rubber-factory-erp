## 4. 隔离站保存与弱网（必须先确认隔离）

准备同产品多订单、明确客户、3张卡、多轮退回、未关联历史、库存已出库等测试样本，记下原件数/重量/分摊/库存余额。

|场景|操作|应见结果|
|---|---|---|
|双击/连续扫码|快速重复扫同卡、双击确认|同物理包只生效一次；重复明确提醒|
|同卡两端并发|电脑和手机同时确认同一退回|一条有效事件；另一次重放或拒绝重复；净交付只回冲一次|
|不同卡并发|两端同时不同卡及不同批确认|两项均有效或明确忙碌可重试，无半账、无串卡|
|保存前断网|填好后关网再保存|不能假成功；输入保留；联网后可明确重试|
|保存中断网|点击保存后丢响应，再联网查询/重试|先核最终状态；不重复入账；页面提示“状态待确认”或实际结果|
|超时重试|限速/延迟导致响应超时|幂等或业务唯一性保护；不得改参数静默复用旧提交|
|快速换卡|A请求延迟时扫描B|A返回不能覆盖B；每卡状态独立，已输入重量/人员不被刷新覆盖|
|撤销再发/更正|退回→撤销→重新登记→再出货→更正|数量与状态可解释；实际返工作业不按重量同比改写|
|库存边界|人工库存出库后再扫描流程卡|未明确关联不再扣库存；余额与流水守恒|

完成后逐笔对平：物理量=份额合计；净交付=全部有效出货−有效回冲；员工归属+未归属差额守恒；协作参与不当全厂额外产量。失败须留下请求时间/ID/界面提示，不能靠刷新后看似正常判定通过。
